## How to verify the voice path (Sol, run this on the host, not inside a worker sandbox)

Workers cannot reach CoreSimulatorService; the acceptance capture must run on the host.

```sh
cd apps/candycorn-ios
/opt/homebrew/bin/xcodegen generate
xcodebuild -project CandyCorn.xcodeproj -scheme CandyCorn -destination 'platform=iOS Simulator,name=iPhone 17' -derivedDataPath /tmp/cc-dd CODE_SIGNING_ALLOWED=NO build test
open -a Simulator
xcrun simctl boot 'iPhone 17' ; xcrun simctl bootstatus 'iPhone 17' -b
xcrun simctl install booted /tmp/cc-dd/Build/Products/Debug-iphonesimulator/CandyCorn.app
xcrun simctl launch --terminate-running-process booted dev.candycorn.app -screen /journal/voice
```

Then in the Simulator window: tap Talk, speak into the Mac microphone for ten seconds, tap Stop, confirm "Saved on this device", tap play and hear it back. The simulator uses the Mac microphone by default (Simulator menu, I/O, Audio Input). If `simctl launch` hangs for every app including Safari, the simulator service is wedged; the fix is `xcrun simctl shutdown all` then `killall -9 com.apple.CoreSimulator.CoreSimulatorService`, which Ethan has to run.

What cannot be verified on the Mac and stays open for the real iPhone: recording while locked, phone-call interruptions, AirPods route changes.

## Known traps from today

- Root cause of the package hang, found 2:30 AM: SwiftPM's Keychain authorization provider. Before downloading the SQLCipher binary artifact (github.com release zip), SwiftPM looks up github.com credentials in the login keychain, finds two entries, and blocks on a Keychain access prompt that no one can click. Zero CPU, no network, no compiler processes; `swift package resolve --disable-keychain` finishes in 4 seconds. Ethan: if a dialog says xcodebuild or swift-package wants to use a github.com item in your keychain, click Always Allow and the builds unblock for good. Workaround used tonight: pre-place `SQLCipher.xcframework` (download with curl, checksum 904823c0e8cc...) at `<DerivedData>/SourcePackages/artifacts/sqlcipher.swift/SQLCipher/` and copy the artifact record from a `swift package resolve --disable-keychain` run into `workspace-state.json`, then build with `-disableAutomaticPackageResolution -scmProvider system`. Also keep `-scmProvider system`; the built-in Git client showed the same symptom on checkouts.

- A worker committed a 366 MB `.pnpm-store` into the repo. It is gitignored now; refuse any commit that adds `node_modules`, `.pnpm-store`, `DerivedData`, `build/`, or `.build`.

- Prototype disclaimers leaked into product copy ("Simulated recording"). Product copy only; test data may be fictional but the words on screen are real.
